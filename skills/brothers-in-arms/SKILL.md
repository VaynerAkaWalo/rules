---
name: brothers-in-arms
description: Have the newest frontier model from another model family verify a merge request before returning its link to the user.
---

Before returning a merge request link to the user, ask the newest available frontier model from a different family to review it, so Claude work goes to the latest GPT and GPT work goes to the latest Claude Opus. Address its findings or answer its objections and send every new round with the full context until both of you agree the merge request is ready to merge, bringing a disagreement you can't resolve to the user instead of looping. Return the link only after that agreement, together with a short note on what the review changed.
